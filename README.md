# 桌游规则复习卡库

一个纯前端本地应用：录入桌游（名称、支持人数、复杂度、上次游玩日期等），把容易忘的规则、常见争议、开局准备和计分提醒做成复习卡，聚会开局前逐条确认。

## 功能

- 新增桌游：名称、最少/最多人数、时长、复杂度、上次游玩日期、封面图。
- 规则卡：按「容易忘的规则 / 常见争议 / 开局准备 / 计分提醒」四类管理；每张卡可切换「已掌握」状态，已掌握的规则不再要求确认。
- 筛选与排序：按关键词、人数（适配所选人数）、复杂度筛选，按最近未玩 / 名称 / 复杂度排序。
- 开局流程：
  1. 在「准备开局」中选择游戏并填写本次人数，人数不在支持区间时给出提示且无法开局；
  2. 开局后每张未掌握规则卡出现「本次确认」勾选；
  3. 所有未掌握规则确认后，「记为已玩」按钮才可点击；
  4. 成功后自动清空本次勾选、把上次游玩日期更新为今天，并保留一条含游戏名、人数、日期的开局记录。
- 进行中的开局及其勾选进度会保留，刷新页面后可继续复习；取消开局不影响已保存数据。
- 统计：收藏数、规则卡总数、累计开局数、最久未玩天数；底部展示历史开局记录。
- 所有数据保存在浏览器 localStorage，刷新后恢复列表、筛选条件、统计和开局状态。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
