# 桌游规则复习卡库

一个纯前端本地应用，用于聚会前快速复习桌游规则。录入游戏名称、支持人数、复杂度和上次游玩日期，按人数与复杂度筛选；每张规则卡可以在本次开局复习中标记"已确认"。

## 使用流程

1. **新增桌游**：填写名称、最少/最多人数、时长、复杂度、上次游玩日期（可选封面图）。
2. **筛选复习**：按搜索关键词、实际人数、复杂度筛选收藏列表并排序。
3. **准备开局**：在详情区输入本次到场人数并开始复习。只有人数在该游戏支持范围内（min–max 人）才允许开局；同一时间只进行一个开局，刷新页面后开局状态恢复。
4. **确认规则**：开局后每条规则卡出现"已确认"勾选框，顶部显示确认进度。
5. **记为已玩**：所有规则卡全部确认后，"记为已玩并结束"按钮才可点击。成功后会：
   - 清空本次全部勾选（结束开局会话）；
   - 把"上次游玩"更新为今天（顶部天数、排序、统计同步刷新）；
   - 在"开局记录"中保留一条记录（游戏、人数、日期）。
6. **放弃本次**：可随时放弃，勾选会清空但不会更新日期，也不产生记录。

## 数据

所有数据（游戏、规则卡、进行中的开局、开局记录）都保存在浏览器 `localStorage`，刷新或重新打开页面后恢复。规则卡有稳定 id，新增/删除不会错勾；旧版本保存的纯文本规则会在加载时自动迁移。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
